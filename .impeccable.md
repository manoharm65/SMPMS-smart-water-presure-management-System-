# SMPMS Design Context

## Design Context

### Users
- Water utility operators at Solapur Municipal Corporation
- Engineers monitoring municipal pipeline pressure across DMA zones
- Administrators managing system configuration
- Context: Control room operations, monitoring real-time telemetry, responding to pressure anomalies and alerts
- Technical level: Moderate — understand pressure readings, valve operations, basic SCADA concepts

### Brand Personality
- Industrial precision: Clean, functional, information-dense
- Reliable: Trustworthy data presentation, clear status indication
- Direct: Action-oriented labels, no fluff, efficient communication

### Aesthetic Direction
- SCADA-inspired dashboard: Dark sidebar, high contrast data displays, monospace typography
- Technical/hierarchical: Clear information hierarchy with KPI-focused layout
- Theme: Light mode primary (control room visibility), dark sidebar for navigation
- Color: Green (OK), Orange (Warning), Red (Critical), Blue (Low) — standard industrial conventions

### Design Principles
1. **Data-first**: Every word should help users understand or act on information
2. **Clear status**: Always show system state clearly (online/offline, auto/manual, normal/critical)
3. **Actionable labels**: Buttons describe the action, not just "Submit" or "OK"
4. **Helpful empty states**: Never just "No data" — explain why or suggest action
5. **Precise terminology**: Consistent terms (valve position, setpoint, pressure) throughout
